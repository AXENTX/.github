# AXENTX Brand Assets

## Logo Files

| File | Usage |
|------|-------|
| `axentx-logo.svg` | Primary logo (light background) |
| `axentx-logo-dark.svg` | Logo for dark backgrounds |
| `axentx-icon.svg` | Icon only (favicons, avatars) |

## Colors

### Primary Blue
- Sky Blue: `#38BDF8`
- Ocean Blue: `#0EA5E9`
- Cyan Accent: `#06B6D4`
- Deep Blue: `#3B82F6`

### Neutrals
- Dark Text: `#0F172A`
- Light Text: `#F8FAFC`
- Light BG: `#F0F9FF`

## Typography

- Font: System UI / Inter / SF Pro
- Weight: 700 (Bold) for logo
- Letter spacing: -1px

## Design Concept

**"Flow"** — คลื่นที่ไหลลื่น สื่อถึง:
- ความราบรื่นในการทำงาน
- Less friction, more flow
- ชีวิตที่สบายขึ้นเมื่อใช้ tools ของเรา

## Usage Guidelines

✅ Do:
- ใช้ logo บน background ที่ contrast ดี
- รักษา proportion ของ logo
- ใช้ icon สำหรับ small sizes

❌ Don't:
- อย่าเปลี่ยนสี gradient
- อย่ายืด/บีบ logo
- อย่าใส่ effects เพิ่ม (shadow, glow)
